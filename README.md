# Clarity

**A thinking tool for better decisions.**

Clarity helps you log important decisions, reflect on your reasoning, track outcomes, and learn from the results over time.

## ✨ Features

- **Decision Logging** – Capture what you decided and *why*
- **Structured Reviews** – Rate the quality of your reasoning and record outcomes
- **Decision Matrix** – Analyze results using Earned / Lucky / Variance / Avoidable quadrants
- **Process Score** – Measure how sound your reasoning is over time
- **Domain Breakdown** – See where your process is strongest
- **Private & Secure** – Built with Supabase + Row Level Security (RLS)

## Tech Stack

- **Frontend**: Next.js (App Router) + Tailwind CSS
- **Backend / Database**: Supabase (PostgreSQL + Auth + RLS)
- **Deployment**: Vercel
